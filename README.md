# CodeAlpha Calculator — Task 2

A responsive calculator built using HTML, CSS, and JavaScript.

## Features
- Addition, subtraction, multiplication, division, and modulo
- Clear all, delete last character, decimal point, and sign toggle
- Keyboard support
- Responsive layout for mobile and desktop
- Error handling for invalid expressions and division by zero

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — calculator functionality

## Run locally
1. Download or extract this folder.
2. Open `index.html` in a modern browser.
3. Click calculator buttons or use your keyboard.

## Keyboard shortcuts
- Numbers and `.`: enter values
- `+`, `-`, `*`, `/`, `%`: operators
- `Enter` or `=`: calculate
- `Backspace`: delete last character
- `Esc` or `Delete`: clear
